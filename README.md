# Mes Projets — tableau de bord iPhone

Application web installable sur iPhone (PWA) pour centraliser tes sites, tes applications et tes projets.

## Mise en ligne sur GitHub Pages

1. Créer un dépôt GitHub `mes-projets-iphone` (public pour un hébergement Pages gratuit sur GitHub Free).
2. Ajouter les fichiers de **ce dossier à la racine du dépôt** : `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`, `README.md`, `.nojekyll`.
3. Dans le dépôt, ouvrir **Settings → Pages**. Sous **Build and deployment**, sélectionner **Deploy from a branch**, branche **main**, dossier **/(root)**, puis **Save**.
4. Une fois le déploiement terminé, accéder à `https://<pseudo>.github.io/mes-projets-iphone/` (remplacer `<pseudo>` par le pseudo GitHub).
5. Sur iPhone, ouvrir l'adresse avec Safari, puis **Partager → Sur l'écran d'accueil → Ajouter**.

Les projets ajoutés sont enregistrés **uniquement dans le stockage local** du navigateur ou de l'app installée ; ce n'est pas une synchronisation GitHub. Exporter régulièrement une sauvegarde JSON depuis les réglages de l'application.
